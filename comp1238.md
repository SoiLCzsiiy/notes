# COMP1238 Notes
## Week 1 - History
- The Babylonian number system used base 60.
- Gutenberg's printing press made books easier and cheaper to produce.
## Week 2 - Bits and Bytes
- A bit represents 0 or 1, and one byte contains 8 bits.
- ASCII represents characters using numbers. For example, 65 represents "A".
## Week 3 - Text Structure
- Markdown uses # for headings and - for bullet lists.
- Escape characters prevent special symbols from being interpreted as formatting.

## Week 4 - Keyboards and Editors
- VS Code is a text editor used for writing and editing code.
- Ctrl + F is used to search for text in a document.

## Week 5 - Command Line Interface
- CLI allows users to interact with a computer by typing commands.
- The ls command lists files, and cd changes directories.
